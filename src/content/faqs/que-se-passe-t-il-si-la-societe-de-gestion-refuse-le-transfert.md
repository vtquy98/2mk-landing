C'est rare. Le notaire vérifie le dossier avant de finaliser. Si la société de gestion refuse (documents incomplets, parts nanties), la transaction est suspendue et les fonds séquestrés sont **intégralement restitués à l'acheteur**. Une fois le problème corrigé, le process reprend.

<div data-rt-embed-type="true"><p>Le refus de transfert par une société de gestion est <strong>rare</strong>, mais peut arriver dans certains cas.</p><h4>Causes possibles de refus</h4><ul><li><strong>Dossier incomplet</strong> : pièce d'identité expirée, justificatif de domicile trop ancien, bordereau SCPI manquant</li><li><strong>Parts nanties</strong> : les parts sont gagées auprès d'une banque (garantie de prêt)</li><li><strong>Parts saisies</strong> : procédure judiciaire en cours</li><li><strong>Indivision non résolue</strong> : tous les indivisaires n'ont pas donné leur accord</li><li><strong>Erreur administrative</strong> : incohérence entre les données du registre et les documents fournis</li></ul><h4>Déroulé</h4><ol><li><strong>Le notaire identifie le blocage</strong> avant de finaliser l'acte</li><li><strong>La transaction est suspendue</strong> (pas annulée immédiatement)</li><li><strong>Les fonds restent en séquestre</strong> chez le notaire — l'acheteur ne perd rien</li><li><strong>Le vendeur corrige le problème</strong> (fournir le document manquant, lever le nantissement)</li><li><strong>Le process reprend</strong> une fois le dossier conforme</li></ol><h4>En cas de refus définitif</h4><p>Si le problème ne peut pas être résolu (exemple : parts définitivement saisies), la transaction est annulée et les fonds sont <strong>intégralement restitués à l'acheteur</strong>.</p><p>C'est précisément pour anticiper ces situations que 2nd Market fait le choix de passer par un notaire : le séquestre protège l'acheteur à chaque étape.</p></div>
