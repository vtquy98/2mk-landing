FORMULES (montants en euros, taux en fraction)
Vente maintenant : M = N x P ; commission = bareme par tranches
(6 / 4 / 3 / 1,5 / 0,75 %) ; notaire = max(bareme 3 / 2 / 1,5 / 0,75 / 0,38 %, 540) ;
net A = M - commission - notaire.
Delai de vente tA (mois, defaut 0) : VA_A = somme(k=1..tA) (N x d / 12) / (1 + i)^(k/12)
                   + net A / (1 + i)^(tA/12).
Attente de T mois : prix attendu R x (1 - b) ; dividendes mensuels N x d / 12 ;
valeur actuelle B = somme(k=1..T) (N x d / 12) / (1 + i)^(k/12)
                   + N x R x (1 - b) x (1 - c) / (1 + i)^(T/12).
Ecart avec la valeur de reference actuelle = B - N x R x (1 - c).
Prix equivalent P* : VA_A(N x P*) = B, soit net A(N x P*) = (B - distributions
actualisees pendant tA) x (1 + i)^(tA/12), par bisection (net A strictement
croissant, derivee >= 0,91). Decote equivalente = 1 - P* / R.

<div class="fso-hyp">
  <p class="fso-hyp-title">Hypothèses et formules</p>
  <ul>
    <li>Vente sur 2nd Market : montant = parts × prix négocié. Commission 2nd Market vendeur, TTC, par tranches : 6 % jusqu'à 50 000 €, 4 % jusqu'à 100 000 €, 3 % jusqu'à 200 000 €, 1,5 % jusqu'à 500 000 €, 0,75 % au-delà, due à la finalisation de la vente. Frais de notaire, TTC, par tranches : 3 %, 2 %, 1,5 %, 0,75 % puis 0,38 %, minimum 540 €. Publication de l'annonce offerte.</li>
    <li>Attente : prix attendu = prix de référence × (1 − baisse). Dividendes modélisés comme versés chaque mois (dividende annuel ÷ 12), par simplification : de nombreuses SCPI versent trimestriellement, l'écart d'actualisation est faible. Commission éventuelle déduite du prix attendu.</li>
